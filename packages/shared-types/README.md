# @leasora/shared-types

Generated TypeScript definitions for the FastAPI HTTP contract.

The source file, [`src/api.ts`](src/api.ts), is generated by
`openapi-typescript`. **Do not edit it manually.** After changing a FastAPI
request model, response model, or route, regenerate and verify the types from
the repository root:

```bash
pnpm gen:types
pnpm type-check
```

See [ADR 004](../../docs/adr/004-no-trpc-why-openapi-codegen.md) for why the
backend OpenAPI schema is the single source of truth.
